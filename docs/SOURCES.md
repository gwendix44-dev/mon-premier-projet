# Fiabilité des contenus

Règle : aucune information n'entre dans l'application sans source, et chaque leçon porte un indicateur.

- **Vérifié** : fait stable (définitions, structure du métier), recoupé avec au moins une source.
- **À vérifier** : chiffres, seuils, tarifs, fiscalité, ou sources surtout commerciales. Ne pas les citer à un client sans contrôle.

## Points d'attention connus
- **TVA** (b7) : les sources se contredisent sur les taux français. La leçon enseigne le réflexe, pas un taux. À compléter avec directive TVA / BOFiP / un fiscaliste.
- **Marge du courtier** (b3) : le « 10 à 15 % » vient de pages commerciales, pas d'une étude sectorielle. Présenté comme ordre de grandeur.
- **Seuils d'heures** (b5) : repères commerciaux (NetJets 1/16 ≈ 50 h/an). Variables selon les programmes.
- **ARGUS / Wyvern** (b6) : niveaux et statuts à revérifier sur les sites des organismes ; les statuts expirent.
- **AOC** (b2) : cadre UE 965/2012, autorité nationale (DGAC en France). Texte primaire : EUR-Lex.
